# 17. Require persisted operations

Since chapter 12 the hub has run persisted operations in shadow mode: every document it registered
runs by id, anything sent as text runs too, and the hub logs what it would refuse. In this chapter
it refuses. The hub then runs only documents it registered when it started, and nothing a caller
writes.

This chapter starts from the end of [chapter 16](/docs/book/checkout-in-the-browser).

## What the hub registers

Every document that reaches the hub now has to be one of these, each under an id with a prefix of
its own:

| Prefix | Whose | Where from |
|---|---|---|
| `trax_client_` | the storefront's | `web/src/graphql/`, through `trax.documents.json` (chapter 15) |
| `trax_machine_` | the checkout machine's operations | generated by the hub for every machine it serves |
| `trax_progress_` | `runProgress`, its query and its subscription | generated by the hub for trains marked `[TraxRunProgress]` |
| `trax_console_` | the operations console's | shipped inside `Trax.Api.Dashboard`, registered by `UseTraxApiDashboard` |

The storefront already sends nothing else, and the console sends its documents by id whenever the
hub runs persisted operations, as it has since chapter 12. Neither changes.

The ids are what make a refusal safe. A document's id is a hash of its text, so an id names exactly
one document, and the hub checked each one against its schema and its rules when it started. A
caller can choose which registered document to run and with which variables, and nothing else.
Who may run each one is still decided by `[TraxAuthorize]` and the operations gate, as before:
persisted operations decide what can be asked, not who may ask it.

## Make the hub refuse

`Shopfront.Hub/Program.cs`:

```csharp compile=app file=Shopfront.Hub/Program.cs
using Shopfront;
using Shopfront.Auth;
using Shopfront.Data;
using Shopfront.Extensions;
using Shopfront.Staff;
using Shopfront.Suppliers;
using Shopfront.Trains.LowStockCheck;
using Shopfront.Trains.Restock;
using Shopfront.Trains.StockReport;
using Trax.Api.Auth.Jwt;
using Trax.Api.Dashboard.Extensions;
using Trax.Api.GraphQL.Extensions;
using Trax.Api.GraphQL.PersistedOperations.Extensions;
using Trax.Effect.Configuration.ClientExport;
using Trax.Effect.Data.Extensions;
using Trax.Effect.Data.Postgres.Extensions;
using Trax.Effect.Data.Services.DomainContext;
using Trax.Effect.Enums;
using Trax.Effect.Extensions;
using Trax.Effect.JunctionProvider.Logging.Extensions;
using Trax.Effect.JunctionProvider.Progress.Extensions;
using Trax.Effect.Models.Manifest;
using Trax.Effect.Provider.Parameter.Extensions;
using Trax.Effect.StateMachine.Persistence;
using Trax.Mediator.Extensions;
using Trax.Scheduler.Extensions;
using Trax.Scheduler.Services.JobSubmitter;
using Trax.Scheduler.Services.Scheduling;

var builder = WebApplication.CreateBuilder(args);

var connectionString =
    builder.Configuration.GetConnectionString("Shopfront")
    ?? throw new InvalidOperationException("ConnectionStrings:Shopfront is not set.");
var development = builder.Environment.IsDevelopment();

builder.Services.AddShopfront(connectionString);

if (development)
    builder.Services.AddTraxJwtAuth(jwt =>
        jwt.UseSymmetricKey(DevJwt.Issuer, DevJwt.Audience, DevJwt.Key)
    );
else
    builder.Services.AddTraxJwtAuth(
        builder.Configuration["Auth:Authority"]
            ?? throw new InvalidOperationException("Auth:Authority is not set."),
        builder.Configuration["Auth:Audience"]
            ?? throw new InvalidOperationException("Auth:Audience is not set.")
    );
builder.Services.AddAuthorization();

// The storefront is served from another origin, which the browser asks the hub to allow.
builder.Services.AddCors(cors =>
    cors.AddDefaultPolicy(policy =>
        policy
            .WithOrigins(
                builder.Configuration["Storefront:Origin"]
                    ?? throw new InvalidOperationException("Storefront:Origin is not set.")
            )
            .AllowAnyHeader()
            .AllowAnyMethod()
    )
);
builder.Services.AddScoped<ISnapshotPrincipal, TraxCallerSnapshotPrincipal>();

builder.Services.AddTrax(trax =>
    trax.AddEffects(effects =>
            effects
                .UsePostgres(connectionString)
                .SaveTrainParameters()
                .AddJunctionLogger(serializeJunctionData: true)
                .AddJunctionProgress()
                .AddDecisionRecording()
                .AddJunctionEvents()
                .AddLifecycleHook<StaffFailureHook>()
        )
        .AddStateMachines(typeof(ManifestNames).Assembly)
        .AddMediator(typeof(ManifestNames).Assembly)
        .AddScheduler(scheduler =>
        {
            // The hub hands every job to the worker through Postgres and runs none itself.
            scheduler.OverrideSubmitter(services =>
                services.AddScoped<IJobSubmitter, PostgresJobSubmitter>()
            );

            // In Development, retries come seconds apart, and a run whose worker died is given up
            // on after a minute rather than an hour, to be watched.
            if (development)
                scheduler
                    .DefaultRetryDelay(TimeSpan.FromSeconds(5))
                    .MaxRetryDelay(TimeSpan.FromSeconds(30))
                    .DefaultJobTimeout(TimeSpan.FromSeconds(30))
                    .StaleInProgressTimeout(TimeSpan.FromMinutes(1));

            return scheduler
                .Schedule<IStockReportTrain>(
                    ManifestNames.StockReport,
                    new StockReportInput(),
                    Cron.Daily(hour: 2),
                    options =>
                        options
                            // The shop's holidays: no count, and none the morning after.
                            .Exclude(
                                Exclude.Dates(new DateOnly(2026, 12, 25), new DateOnly(2027, 1, 1))
                            )
                            .OnMisfire(MisfirePolicy.DoNothing)
                            .Variance(TimeSpan.FromMinutes(10))
                )
                .ThenInclude<ILowStockCheckTrain>(
                    ManifestNames.LowStockCheck,
                    new LowStockCheckInput { Threshold = 3 }
                )
                .Schedule<IRestockTrain>(
                    ManifestNames.Restock,
                    new RestockInput { Threshold = 3 },
                    development ? Every.Minutes(1) : Every.Hours(1),
                    options => options.MaxRetries(2)
                );
        })
);

// Only registered documents run. PersistedOperations:Require=false lets documents written as text
// run too, for the tests and for exploring by hand, and is read in Development only: anywhere else
// the setting is ignored.
var requirePersisted =
    !development || builder.Configuration.GetValue("PersistedOperations:Require", true);

builder.Services.AddTraxGraphQL(graphql =>
    graphql
        .AddDbContext<ShopfrontDbContext>()
        .ExposeOperationQueries()
        .ExposeOperationMutations()
        .GateOperations(roles: Roles.Staff)
        .UsePersistedOperations(persisted =>
        {
            persisted
                .SingleNode()
                .RequirePersisted(requirePersisted)
                .LogNonPersistedRequests(!requirePersisted)
                // The storefront's documents, which trax client writes and the build copies here.
                .ClientDocuments(Path.Combine(AppContext.BaseDirectory, "trax.documents.json"));
            // Introspection is a document written as text too.
            if (requirePersisted)
                persisted.DisableIntrospection();
        })
);

var app = builder.Build();

// An export of the client manifest opens no database.
if (!TraxClientExport.Requested)
    await app.Services.EnsureSchemaCreatedAsync<ShopfrontDbContext>();

app.UseCors();
app.UseAuthentication();
app.UseAuthorization();
app.UseTraxGraphQL();
app.UseTraxApiDashboard(dashboard => dashboard.AllowAnonymousShell());

if (development)
{
    app.MapGet(
            "/dev/token/{user}",
            (string user, bool staff = false) =>
                DevJwt.Mint(user, staff ? Roles.Staff : Roles.Customer)
        )
        .AllowAnonymous();

    // Takes this process's fake supplier down, or brings it back.
    app.MapPost(
            "/dev/supplier/{state}",
            (string state, FakeSupplier supplier) =>
            {
                supplier.IsDown = state == "down";
                return Results.NoContent();
            }
        )
        .AllowAnonymous();
}

// Serves, or with --trax-export-client writes the client manifest and exits.
await app.RunTraxAsync(args);
```

What changed:

- **`RequirePersisted(requirePersisted)`** is on wherever the hub runs. A document sent as text is
  refused, on HTTP and on the socket, with `PERSISTED_OPERATION_REQUIRED`.
- **`LogNonPersistedRequests`** goes with shadow mode, so it is on only when text may run.
- **`DisableIntrospection()`.** Introspection is a document written as text as well, the one a
  tool sends to read the schema, and a host that runs only its own documents has no caller who
  needs it. `trax client` reads the manifest, not the schema.
- **`PersistedOperations:Require`** can turn the refusal off, in Development only. Outside
  Development the hub ignores it, so a deployed hub cannot be configured into accepting text. It
  is there for the tests and for exploring by hand with `curl`.

## What a caller sees

Start the hub, and send the catalogue's document as text, as chapter 7 did:

```bash
curl -s -w ' %{http_code}' http://localhost:5080/trax/graphql -H 'Content-Type: application/json' \
  -d '{"query":"{ discover { products(order: { sku: ASC }) { nodes { sku name price stock } } } }"}'
```

```text
{"errors":[{"message":"Only persisted operations are accepted on this server.","extensions":{"code":"PERSISTED_OPERATION_REQUIRED"}}]} 400
```

The same document by the id the storefront's client holds runs:

```bash
CAT=$(grep -o 'trax_client_Catalogue_[a-z0-9]*' web/src/trax/documents/catalogue.g.ts)
curl -s http://localhost:5080/trax/graphql -H 'Content-Type: application/json' -d '{"id":"'$CAT'"}'
```

```text
{"data":{"discover":{"products":{"nodes":[{"sku":"CAP","name":"Cap","price":18.50,"stock":0},{"sku":"MUG","name":"Mug","price":12.00,"stock":10},{"sku":"TEE","name":"T-shirt","price":25.00,"stock":3}]}}}}
```

Introspection is refused the same way. The hub says at start which mode it is in:

```text
info: Trax.Api.GraphQL.PersistedOperations[0]
      Persisted-operation enforcement is ON. An inline query is refused unless it is allowlisted, introspection, or selects only the persisted-operations management surface. Enforcement shapes requests and is not an authorization boundary: per-type [TraxAuthorize] still decides who may run what.
```

The storefront works as it did: open it, check out and buy now. So does the console: sign in as
`lin` and it lists the runs, because each of its pages sends a document the hub registered. Its
entry page names the ids:

```text
71 documents; Executions -> trax_console_Executions_ea98447121dc28f08cf3d51a272418b4611c...
```

## What stops working

- **`curl` with a document written as text**, which every earlier chapter used. In Development,
  start the hub with `PersistedOperations__Require=false` to explore by hand again.
- **The GraphQL IDE** at `/trax/graphql` sends text and introspects. It is served in Development
  only, and refused with the rest there now.
- **A client this hub did not generate.** A mobile app, a partner's integration or a script that
  writes its own documents has to have them registered: as documents of its own, through
  `trax client --documents` like the storefront's, or uploaded through the persisted-operations
  management fields.

## Test it

The host tests write their documents as text. A fixture for the folder sets the Development-only
switch for the whole run:

`tests/Shopfront.Tests/IntegrationTests/DocumentsAsText.cs`:

```csharp compile=tests file=tests/Shopfront.Tests/IntegrationTests/DocumentsAsText.cs
namespace Shopfront.Tests.IntegrationTests;

// The host tests write their documents as text, which the hub refuses. For the whole run they set
// the Development-only switch that lets text run; a test that checks the refusal sets it back.
[SetUpFixture]
public class DocumentsAsText
{
    private const string Switch = "PersistedOperations__Require";

    [OneTimeSetUp]
    public void LetTextRun() => Environment.SetEnvironmentVariable(Switch, "false");

    [OneTimeTearDown]
    public void Restore() => Environment.SetEnvironmentVariable(Switch, null);
}
```

One test class checks the refusal itself, with the switch set back. It needs a registered
document's id: the client manifest the storefront is generated from holds the checkout's, and the
test project copies it beside the tests.

`tests/Shopfront.Tests/IntegrationTests/PersistedOperationsTests.cs`:

```csharp compile=tests file=tests/Shopfront.Tests/IntegrationTests/PersistedOperationsTests.cs
using System.Net;
using System.Net.Http.Headers;
using System.Net.Http.Json;
using System.Text.Json;
using Microsoft.AspNetCore.Hosting;
using Microsoft.AspNetCore.Mvc.Testing;
using Shopfront.Auth;
using Trax.Effect.StateMachine;

namespace Shopfront.Tests.IntegrationTests;

[TestFixture]
public class PersistedOperationsTests
{
    private static readonly ClientManifest Manifest = ClientManifest.Read(
        File.ReadAllText(Path.Combine(AppContext.BaseDirectory, "manifest.json"))
    );

    private static readonly ClientManifestDocument StartCheckout = Manifest
        .Machines.Single(m => m.Id == "checkout")
        .Documents.Single(d => d.Operation == "start");

    private WebApplicationFactory<Program> _app = null!;

    [SetUp]
    public async Task StartTheApplication()
    {
        await TestDatabase.Reset();
        _app = new WebApplicationFactory<Program>().WithWebHostBuilder(host =>
            host.UseEnvironment("Development")
                .UseSetting("ConnectionStrings:Shopfront", TestDatabase.ConnectionString)
                // As deployed: only registered documents run.
                .UseSetting("PersistedOperations:Require", "true")
        );
    }

    [TearDown]
    public ValueTask StopTheApplication() => _app.DisposeAsync();

    private HttpClient Ada()
    {
        var client = _app.CreateClient();
        client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue(
            "Bearer",
            DevJwt.Mint("ada", Roles.Customer)
        );
        return client;
    }

    [Test]
    public async Task ARegisteredDocument_SentByItsId_Runs()
    {
        using var ada = Ada();

        var response = await ada.PostAsJsonAsync(
            "/trax/graphql",
            new { id = StartCheckout.Id, variables = new { requestId = "s" } }
        );

        var body = await response.Content.ReadFromJsonAsync<JsonElement>();
        body.GetProperty("data")
            .GetProperty("machines")
            .GetProperty("checkout")
            .GetProperty("start")
            .GetProperty("state")
            .GetString()
            .Should()
            .Be("Cart");
    }

    [Test]
    public async Task TheSameDocument_SentAsText_IsRefused()
    {
        using var ada = Ada();

        var response = await ada.PostAsJsonAsync(
            "/trax/graphql",
            new { query = StartCheckout.Document, variables = new { requestId = "s" } }
        );

        response.StatusCode.Should().Be(HttpStatusCode.BadRequest);
        var body = await response.Content.ReadFromJsonAsync<JsonElement>();
        body.ErrorCodes().Should().Equal("PERSISTED_OPERATION_REQUIRED");
    }
}
```

## What we have

The hub runs the documents it registered and nothing else: the storefront's, the ones it generates
for its machines and for following runs, and the console's. A document sent as text is refused in
every environment, unless a developer turns that off on their own machine.

The last chapter deploys Shopfront.
