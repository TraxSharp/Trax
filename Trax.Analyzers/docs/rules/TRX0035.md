# TRX0035 - Do not use dangerous threading methods
<!-- sources -->
Source: [DontUseDangerousThreadingMethodsAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/DontUseDangerousThreadingMethodsAnalyzer.cs)
<!-- sources -->

This rule warns about using the methods `Abort()`, `Suspend()` or `Resume()` declared by the `Thread` class.
