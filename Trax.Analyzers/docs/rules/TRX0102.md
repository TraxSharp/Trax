# TRX0102 - Make member readonly
<!-- sources -->
Sources: [MakeMemberReadOnlyAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/MakeMemberReadOnlyAnalyzer.cs), [MakeMemberReadOnlyFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/MakeMemberReadOnlyFixer.cs)
<!-- sources -->

A struct member should use the `readonly` modifier when it does not modify state.

> **Note**
> This rule is enabled when using C# 8 or later

The partial methods and the partial properties are not reported, as all their parts must be `readonly`.

````c#
struct Sample
{
    int a;

    public int A => a; // non-compliant
}
````

````c#
struct Sample
{
    int a;

    public readonly int A => a; // compliant
}
````
