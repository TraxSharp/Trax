# TRX0059 - Class name should end with 'EventArgs'
<!-- sources -->
Sources: [EventArgsNameShouldEndWithEventArgsAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/EventArgsNameShouldEndWithEventArgsAnalyzer.cs), [TypeNameShouldEndWithSuffixFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/TypeNameShouldEndWithSuffixFixer.cs)
<!-- sources -->

A class that derives from `System.EventArgs` should have a name that ends with 'EventArgs'.

````csharp
class Sample : EventArgs // Non compliant
{
}
````

````csharp
class SampleEventArgs : EventArgs // compliant
{
}
````
