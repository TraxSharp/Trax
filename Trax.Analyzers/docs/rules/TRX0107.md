# TRX0107 - Do not use object.ToString
<!-- sources -->
Source: [DoNotUseImplicitCultureSensitiveToStringAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/DoNotUseImplicitCultureSensitiveToStringAnalyzer.cs)
<!-- sources -->

````csharp
object a = 10;
_ = a.ToString(); // not-compliant as it uses the default object.ToString() implementation

sealed class Sample {}

var sample = new Sample();
_ = $"{sample}"; // not-compliant as it uses the default object.ToString() implementation
````

## Configuration

````
# Exclude ToString methods from analysis
TRX0107.exclude_tostring_methods=true
````
