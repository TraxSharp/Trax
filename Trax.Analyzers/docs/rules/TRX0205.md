# TRX0205 - Use exclusive or operator
<!-- sources -->
Sources: [UseExclusiveOrOperatorAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/UseExclusiveOrOperatorAnalyzer.cs), [UseExclusiveOrOperatorFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/UseExclusiveOrOperatorFixer.cs)
<!-- sources -->

This rule reports boolean expressions that can be simplified by using the exclusive or (`^`) operator.

## Non-compliant code

````csharp
var result = (x && !y) || (!x && y);
````

## Compliant code

````csharp
var result = x ^ y;
````
