# TRX0174 - Record should use explicit 'class' keyword
<!-- sources -->
Sources: [RecordClassDeclarationShouldBeExplicitAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/RecordClassDeclarationShouldBeExplicitAnalyzer.cs), [RecordClassDeclarationShouldBeExplicitFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/RecordClassDeclarationShouldBeExplicitFixer.cs)
<!-- sources -->

This rule suggests adding the explicit `class` keyword to record declarations that don't specify it.

```csharp
public sealed record Customer;       // non-compliant
public sealed record class Customer; // compliant
```

## Related rules

- [TRX0175](TRX0175.md) - Record should not use explicit 'class' keyword (opposite rule)
