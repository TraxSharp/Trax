# TRX0027 - Prefer rethrowing an exception implicitly
<!-- sources -->
Sources: [DoNotRemoveOriginalExceptionFromThrowStatementAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/DoNotRemoveOriginalExceptionFromThrowStatementAnalyzer.cs), [DoNotRemoveOriginalExceptionFromThrowStatementFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/DoNotRemoveOriginalExceptionFromThrowStatementFixer.cs)
<!-- sources -->

When an exception is rethrown explicitly (i.e. by specifying it), the original stack trace will be lost, replaced by a new one.
To preserve the original call stack, rethrow the exception implicitly (i.e. without specifying it).

```csharp
try
{
}
catch (Exception ex)
{
    throw ex;
}

// Should be
try
{
}
catch (Exception ex)
{
    throw;
}
```
