# TRX0137 - Use 'Async' suffix when a method returns an awaitable type
<!-- sources -->
Sources: [MethodsReturningAnAwaitableTypeMustHaveTheAsyncSuffixAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/MethodsReturningAnAwaitableTypeMustHaveTheAsyncSuffixAnalyzer.cs), [MethodsReturningAnAwaitableTypeMustHaveTheAsyncSuffixFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/MethodsReturningAnAwaitableTypeMustHaveTheAsyncSuffixFixer.cs)
<!-- sources -->

Methods that return awaitable types such as `Task` or `ValueTask` should have an Async suffix.

````c#
// compliant
Task FooAsync() => Task.CompletedTask;

// non-compliant
Task Foo() => Task.CompletedTask;
````

The following are excluded from this rule by default:

- Property accessors (properties are named by convention, not their accessors)
- Methods with well-known names that are part of the awaitable pattern: `ConfigureAwait`, `GetAwaiter`, `WithCancellation`

User-defined operators and conversion operators are never reported, as their names are defined by the language.

# Configuration

By default, test methods (methods decorated with test framework attributes such as `[Fact]`, `[Test]`, `[TestMethod]`, etc.) are excluded from this rule. You can change this behavior using the `.editorconfig` file:

````editorconfig
TRX0137.exclude_test_methods = true # default value
````

Set to `false` to also report diagnostics on test methods:

````editorconfig
TRX0137.exclude_test_methods = false
````

By default, property and event accessors are excluded from this rule. You can change this behavior using the `.editorconfig` file:

````editorconfig
TRX0137.exclude_property_accessors = true # default value
````

Set to `false` to also report diagnostics on property and event accessors:

````editorconfig
TRX0137.exclude_property_accessors = false
````

You can also mark specific types as non-awaitable using `NonAwaitableTypeAttribute`. Methods returning those types are ignored by TRX0137.
To use `Trax.Analyzers.Annotations.NonAwaitableTypeAttribute`, add the `Trax.Analyzers.Annotations` NuGet package (or copy the attribute source into your project). See [Trax.Analyzers.Annotations README](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.Annotations/README.md).

```csharp
[assembly: Trax.Analyzers.Annotations.NonAwaitableTypeAttribute(typeof(MyTaskResult))]
```

The match is exact-type only. Derived types are not excluded unless explicitly listed.
