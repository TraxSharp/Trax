# TRX0087 - Parameters with \[DefaultParameterValue\] attributes should also be marked \[Optional\]
<!-- sources -->
Sources: [OptionalParametersAttributeAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/OptionalParametersAttributeAnalyzer.cs), [OptionalParametersAttributeFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/OptionalParametersAttributeFixer.cs)
<!-- sources -->

````csharp
using System.Runtime.InteropServices;
class Test
{
    void A([Optional, DefaultParameterValue(10)]int a)
    {
    }

    void B([DefaultParameterValue(10)]int a) // Non-compliant
    {
    }
}
````
