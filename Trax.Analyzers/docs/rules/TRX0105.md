# TRX0105 - Use the lambda parameters instead of using a closure
<!-- sources -->
Sources: [AvoidClosureWhenUsingConcurrentDictionaryAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/AvoidClosureWhenUsingConcurrentDictionaryAnalyzer.cs), [AvoidClosureWhenUsingConcurrentDictionaryFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/AvoidClosureWhenUsingConcurrentDictionaryFixer.cs)
<!-- sources -->

````c#
var key = 1;
var dict = new ConcurrentDictionary<int, string>();
dict.GetOrAdd(key, _ => $"{key}"); // report diagnostic

dict.GetOrAdd(key, k => $"{k}"); // ok
````
