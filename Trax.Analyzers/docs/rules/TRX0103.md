# TRX0103 - Use SequenceEqual instead of equality operator
<!-- sources -->
Sources: [DoNotUseEqualityOperatorsForSpanOfCharAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/DoNotUseEqualityOperatorsForSpanOfCharAnalyzer.cs), [DoNotUseEqualityOperatorsForSpanOfCharFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/DoNotUseEqualityOperatorsForSpanOfCharFixer.cs)
<!-- sources -->

````c#
using System;

"".AsSpan() == "".AsSpan(); // non-compliant
````

````c#
using System;

"".AsSpan().SequenceEqual("".AsSpan());
````
