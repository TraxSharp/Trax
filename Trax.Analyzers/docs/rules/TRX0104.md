# TRX0104 - Do not create a type with a name from the BCL
<!-- sources -->
Source: [DotNotUseNameFromBCLAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/DotNotUseNameFromBCLAnalyzer.cs)
<!-- sources -->

````c#
public class String // TRX0104
{
}
````

You can configure the types and namespaces to consider in the `.editorconfig` file

````
TRX0104.namespaces_regex = ^System($|\.)
TRX0104.use_preview_types = true # use types from preview versions of .NET
````

If `TRX0104.namespaces_regex` is not a valid regular expression, the default value (`^System($|\.)`) is used and [TRX0220](TRX0220.md) is reported. The default value is also used when the value is empty.

By default, the rule only applies to public types. Add the following line to the `.editorconfig` file to consider all types:

````
TRX0104.only_consider_public_symbols = false
````
