# TRX0029 - Combine LINQ methods
<!-- sources -->
Sources: [OptimizeLinqUsageAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/OptimizeLinqUsageAnalyzer.cs), [OptimizeLinqUsageFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/OptimizeLinqUsageFixer.cs)
<!-- sources -->

Combine LINQ methods when possible.

```csharp
new int[0].Where(x => true).Any();

// Should be
new int[0].Any(x => true);
```

The rule does not report the calls whose predicate cannot be combined, such as `Where((x, index) => ...)`, or `FirstOrDefault(defaultValue)` whose argument is not a predicate.
