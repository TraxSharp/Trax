# TRX0168 - Use readonly struct for in or ref readonly parameter
<!-- sources -->
Source: [UseReadOnlyStructForRefReadOnlyParametersAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/UseReadOnlyStructForRefReadOnlyParametersAnalyzer.cs)
<!-- sources -->

```c#
void A(in Foo p) { } // not-compliant as Foo is not readonly

struct Foo { }
```

```c#
void A(in Foo p) { } // ok

readonly struct Foo { }
```
