# TRX0033 - Do not tag instance fields with ThreadStaticAttribute
<!-- sources -->
Source: [DontTagInstanceFieldsWithThreadStaticAttributeAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/DontTagInstanceFieldsWithThreadStaticAttributeAnalyzer.cs)
<!-- sources -->

```csharp
[ThreadStatic]
private string _field;

// Should be
[ThreadStatic]
private static string _field;
```
