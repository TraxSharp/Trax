# TRX0182 - Avoid unused internal types

This analyzer detects internal types (classes, structs, records, record structs) that are never used.

## How to fix violations

1. If the type is truly unused, remove it from the codebase. The code fix removes all the declarations of a partial type.
2. If the type is accessed using reflection, consider adding the `[DynamicallyAccessedMembers]` attribute.
