# TRX0020 - Use direct methods instead of LINQ methods

Sources: [OptimizeLinqUsageAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/OptimizeLinqUsageAnalyzer.cs), [OptimizeLinqUsageFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/OptimizeLinqUsageFixer.cs)

By default, the rule generates a diagnostic only when arguments do not need conversion. You can configure the rule to always report diagnostics, as follows:

````
[*.cs]
TRX0020.report_when_conversion_needed=true
````
