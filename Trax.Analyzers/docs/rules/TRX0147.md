# TRX0147 - Avoid async void method for delegate
<!-- sources -->
Source: [DoNotUseAsyncDelegateForSyncDelegateAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/DoNotUseAsyncDelegateForSyncDelegateAnalyzer.cs)
<!-- sources -->

````c#
Foo(() => {}); // ok

Foo(async () => {}); // non-compliant as the delegate is not expecting an async method

Foo(Handler); // non-compliant as the delegate is not expecting an async method

async void Handler() { }

void Foo(System.Action action) => throw null;
````
