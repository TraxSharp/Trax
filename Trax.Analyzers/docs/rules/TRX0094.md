# TRX0094 - A class that provides CompareTo(T) should implement IComparable\<T\>
<!-- sources -->
Sources: [EqualityShouldBeCorrectlyImplementedAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/EqualityShouldBeCorrectlyImplementedAnalyzer.cs), [EqualityShouldBeCorrectlyImplementedFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/EqualityShouldBeCorrectlyImplementedFixer.cs)
<!-- sources -->

````c#
class Test // non-compliant
{
    public int CompareTo(Test other) => throw null;
}

class Test : IComparable<T> // ok
{
    public int CompareTo(Test other) => throw null;
}
````
