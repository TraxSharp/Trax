# TRX0080 - Use a cancellation token using .WithCancellation()
<!-- sources -->
Source: [UseAnOverloadThatHasCancellationTokenAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/UseAnOverloadThatHasCancellationTokenAnalyzer.cs)
<!-- sources -->

````c#
IAsyncEnumeration<string> enumerable;
await foreach (var item in enumerable) // not compliant
{
}

await foreach (var item in enumerable.WithCancellation(cancellationToken)) // compliant
{
}
````

## Exclude a method from this rule

The method returning the enumerable can be marked as valid to call without a `CancellationToken` using [`ExcludeFromCancellationTokenAnalysisAttribute`](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.Annotations/README.md) from the `Trax.Analyzers.Annotations` package.

````c#
[Trax.Analyzers.Annotations.ExcludeFromCancellationTokenAnalysis]
static IAsyncEnumerable<string> Enumerate() => throw null;

await foreach (var item in Enumerate()) // compliant
{
}
````

The methods of another assembly can be excluded at the assembly level, using their XML documentation id or their containing type and name:

````c#
[assembly: Trax.Analyzers.Annotations.ExcludeFromCancellationTokenAnalysis("M:Sample.Enumerate")]
[assembly: Trax.Analyzers.Annotations.ExcludeFromCancellationTokenAnalysis(typeof(Sample), "Enumerate")]
````
