# TRX0081 - Method overrides should not omit params keyword
<!-- sources -->
Sources: [PreserveParamsOnOverrideAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/PreserveParamsOnOverrideAnalyzer.cs), [PreserveParamsOnOverrideFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/PreserveParamsOnOverrideFixer.cs)
<!-- sources -->

````csharp
class Base
{
  public virtual void Method(params int[] numbers) => { };
}

class Derived : Base
{
  public override void Method(int[] numbers) // non-compliant: "params" is missing
  {
  }
}
````
