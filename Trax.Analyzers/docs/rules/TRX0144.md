# TRX0144 - Use System.OperatingSystem to check the current OS
<!-- sources -->
Sources: [UseOperatingSystemInsteadOfRuntimeInformationAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/UseOperatingSystemInsteadOfRuntimeInformationAnalyzer.cs), [UseOperatingSystemInsteadOfRuntimeInformationFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/UseOperatingSystemInsteadOfRuntimeInformationFixer.cs)
<!-- sources -->

Use `System.OperatingSystem` to check the current OS instead of `RuntimeInformation`.

````c#
RuntimeInformation.IsOSPlatform(OSPlatform.Windows); // non-compliant

OperatingSystem.IsWindows(); // ok
````
