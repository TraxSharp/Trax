# TRX0175 - Record should not use explicit 'class' keyword
<!-- sources -->
Sources: [RecordClassDeclarationShouldBeImplicitAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/RecordClassDeclarationShouldBeImplicitAnalyzer.cs), [RecordClassDeclarationShouldBeImplicitFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/RecordClassDeclarationShouldBeImplicitFixer.cs)
<!-- sources -->

This rule suggests removing the explicit `class` keyword from record declarations.

```csharp
public sealed record class Customer; // non-compliant
public sealed record Customer;       // compliant
```
