# TRX0116 - Parameters with \[SupplyParameterFromQuery\] attributes should also be marked as \[Parameter\]
<!-- sources -->
Sources: [ParameterAttributeForRazorComponentAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/ParameterAttributeForRazorComponentAnalyzer.cs), [ParameterAttributeForRazorComponentFixer.AddParameterAttribute.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/ParameterAttributeForRazorComponentFixer.AddParameterAttribute.cs)
<!-- sources -->

Detects when `[SupplyParameterFromQuery]` attributes are used without the `[Parameter]` attribute.

````razor
using Microsoft.AspNetCore.Components;

@code {
    [SupplyParameterFromQuery] // non-compliant
    public int A { get; set; }

    [Parameter]
    [SupplyParameterFromQuery] // ok as the property has the Parameter attribute
    public int B { get; set; }
}
````
