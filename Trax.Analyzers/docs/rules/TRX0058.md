# TRX0058 - Class name should end with 'Exception'
<!-- sources -->
Sources: [ExceptionNameShouldEndWithExceptionAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/ExceptionNameShouldEndWithExceptionAnalyzer.cs), [TypeNameShouldEndWithSuffixFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/TypeNameShouldEndWithSuffixFixer.cs)
<!-- sources -->

A class that derives from `System.Exception` should have a name that ends with 'Exception'.

````csharp
class Sample : Exception // Non compliant
{
}
````

````csharp
class SampleException : Exception // compliant
{
}
````
