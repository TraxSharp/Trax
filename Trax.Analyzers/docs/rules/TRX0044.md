# TRX0044 - Remove useless ToString call
<!-- sources -->
Sources: [RemoveUselessToStringAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/RemoveUselessToStringAnalyzer.cs), [RemoveUselessToStringFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/RemoveUselessToStringFixer.cs)
<!-- sources -->

`string.ToString` is a no-op call. You should remove the call to `ToString()`.

````csharp
var str = "abc";
Console.Write(str.ToString()); // non compliant
````

````csharp
var str = "abc";
Console.Write(str); // compliant
````

The code fix is not offered when the call has an argument whose evaluation may have side effects, such as `str.ToString(GetFormatProvider())`, as removing the call would also remove the evaluation of the argument.
