# TRX0155 - Do not use async void methods
<!-- sources -->
Source: [DoNotUseAsyncVoidAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/DoNotUseAsyncVoidAnalyzer.cs)
<!-- sources -->

```c#
// non-compliant
async void SomeMethod()
{
    await Task.Delay(1000);
}

// ok
async Task SomeMethod()
{
    await Task.Delay(1000);
}
```
