# TRX0146 - Name must be set explicitly on local functions
<!-- sources -->
Sources: [ValidateUnsafeAccessorAttributeUsageAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/ValidateUnsafeAccessorAttributeUsageAnalyzer.cs), [ValidateUnsafeAccessorAttributeUsageFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/ValidateUnsafeAccessorAttributeUsageFixer.cs)
<!-- sources -->

Local function names are mangled by the compiler, so the `Name` parameter is required. The rule is not reported for `UnsafeAccessorKind.Constructor`, as the name of a constructor accessor is not used.

````c#
// non compliant
void Sample()
{
    [UnsafeAccessor(UnsafeAccessorKind.Field)]
    extern static ref int _Major_(System.Version a);
}

// Ok
void Sample()
{
    [UnsafeAccessor(UnsafeAccessorKind.Field, Name = "_Major")]
    extern static ref int _Major_(System.Version a);
}
````
