# TRX0074 - Avoid implicit culture-sensitive methods
<!-- sources -->
Sources: [UseStringComparisonAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/UseStringComparisonAnalyzer.cs), [UseStringComparisonFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/UseStringComparisonFixer.cs)
<!-- sources -->

String manipulation methods in .NET do not all use the same default rules for string comparison by culture and case. For instance, `string.Equals(string, string)` uses `StringComparison.Ordinal` whereas `IndexOf(String)` uses `StringComparison.CurrentCulture`. So, you should use an overload that does not rely on default behavior.

TRX0074 only reports a diagnostic when the default comparison for the method is not `Ordinal` and not `OrdinalIgnoreCase`. [`TRX0001`](./TRX0001.md) reports all other cases.

````csharp
"a".StartsWith("b"); // non-compliant as the default comparison of StartsWith is CurrentCulture

// Should be
"a".StartsWith("b", StringComparison.Ordinal);
````

## Configuration

````
# Include the overloads that are extension methods declared in a namespace that is not imported. The code fix adds the using directive. default: false
TRX0074.include_extension_methods_from_not_imported_namespaces = false
````
