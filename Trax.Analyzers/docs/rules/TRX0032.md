# TRX0032 - Use an overload with a CancellationToken argument, even when no token is available in scope
<!-- sources -->
Source: [UseAnOverloadThatHasCancellationTokenAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/UseAnOverloadThatHasCancellationTokenAnalyzer.cs)
<!-- sources -->

You should pass a `CancellationToken` when calling a method if there is an overload of the method that supports it, even if there is no `CancellationToken` available in the current scope.

````csharp
class Test
{
    public void A(CancellationToken cancellationToken)
    {
        MethodWithCancellationToken(); // non compliant
        MethodWithCancellationToken(cancellationToken); // compliant
    }

    public void MethodWithCancellationToken() => throw null;
    public void MethodWithCancellationToken(System.Threading.CancellationToken cancellationToken) => throw null;
}
````

## Configuration

````
TRX0032.allow_overloads_with_optional_parameters = false

# Include the overloads that are extension methods declared in a namespace that is not imported. The code fix adds the using directive. default: false
TRX0032.include_extension_methods_from_not_imported_namespaces = false
````

The previous name of this option, `TRX0032.allowOverloadsWithOptionalParameters`, is still supported.

````c#
Foo.Bar(); // report when TRX0032.allow_overloads_with_optional_parameters is true

class Foo
{
    public static void Bar() => throw null;
    public static void Bar(CancellationToken cancellationToken, bool dummy = false) => throw null;
}
````

## Exclude a method from this rule

A method can be marked as valid to call without a `CancellationToken` using [`ExcludeFromCancellationTokenAnalysisAttribute`](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.Annotations/README.md) from the `Trax.Analyzers.Annotations` package. No diagnostic is reported for the calls to an excluded method.

````c#
class Sample
{
    [Trax.Analyzers.Annotations.ExcludeFromCancellationTokenAnalysis]
    public static void Flush() => throw null;
    public static void Flush(CancellationToken cancellationToken) => throw null;
}

Sample.Flush(); // compliant
````

The methods of another assembly can be excluded at the assembly level, using their XML documentation id or their containing type and name:

````c#
[assembly: Trax.Analyzers.Annotations.ExcludeFromCancellationTokenAnalysis("M:Sample.Flush")]
[assembly: Trax.Analyzers.Annotations.ExcludeFromCancellationTokenAnalysis(typeof(Sample), "Flush")]
````
