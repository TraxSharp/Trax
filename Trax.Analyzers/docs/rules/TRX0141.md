# TRX0141 - Use 'is not null' instead of '!= null'
<!-- sources -->
Sources: [UsePatternMatchingForEqualityComparisonsAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/UsePatternMatchingForEqualityComparisonsAnalyzer.cs), [UsePatternMatchingForEqualityComparisonsFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/UsePatternMatchingForEqualityComparisonsFixer.cs)
<!-- sources -->

````c#
value != null; // not compliant

value is not null; // ok
````

Comparisons with a `dynamic` operand are ignored, as the operator is bound at runtime and may be a user-defined operator:

````c#
dynamic value = null;
_ = value != null; // ok
````
