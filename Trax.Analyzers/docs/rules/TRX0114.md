# TRX0114 - Use DateTimeOffset.UnixEpoch
<!-- sources -->
Sources: [UseDateTimeUnixEpochAnalyzer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers/Rules/UseDateTimeUnixEpochAnalyzer.cs), [UseDateTimeUnixEpochFixer.cs](https://github.com/TraxSharp/Trax/blob/main/Trax.Analyzers/src/Trax.Analyzers.CodeFixers/Rules/UseDateTimeUnixEpochFixer.cs)
<!-- sources -->

Use `System.DateTimeOffset.UnixEpoch` instead of re-implementing the logic.

````c#
_ = new DateTimeOffset(1970, 1, 1, 0, 0, 0, TimeSpan.Zero); // report diagnostic

_ = DateTimeOffset.UnixEpoch; // ok
````
